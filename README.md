# 💳 MyCard Flutter

Cartão digital pessoal desenvolvido em **Flutter**, com informações de contato e links clicáveis.  
Projeto acadêmico transformado em portfólio profissional.

---

## 🧩 Sobre o Projeto

O **MyCard Flutter** é um aplicativo simples e elegante que apresenta um cartão digital com:
- Foto de perfil (avatar ilustrativo)
- Nome e título profissional
- Informações de contato (telefone, e-mail e localização)
- Link direto para o perfil no GitHub

O objetivo é demonstrar o uso de **Flutter** para criar interfaces modernas e interativas, aplicando conceitos de layout, widgets e integração com links externos.

> ⚠️ **Observação:** A imagem utilizada é **ilustrativa**, criada para representar um avatar genérico.  
> Nenhuma foto pessoal foi utilizada para preservar privacidade.

---

## 🛠️ Tecnologias Utilizadas

- **Flutter** — framework principal  
- **Dart** — linguagem de programação  
- **url_launcher** — para abrir links e ações externas  
- **Material Design** — para estilização e componentes visuais
